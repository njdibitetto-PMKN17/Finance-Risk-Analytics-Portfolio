# Full Analysis Report

This folder contains the sanitized HTML report for the Credit Risk Detection & Monitoring Dashboard.

GitHub may not preview the report directly because it is a large exported notebook HTML file.

To view it:

1. Click `credit_risk_detection_monitoring_report.html`.
2. Click **Download raw file** or **Raw**.
3. Open the downloaded `.html` file locally in Chrome, Edge, or another browser.

The report documents the full workflow, methodology, scoring logic, validation checks, forecast interpretation, limitations, and business conclusions behind the main projects solutions and the Streamlit dashboard.
