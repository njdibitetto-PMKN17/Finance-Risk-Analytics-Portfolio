# Credit Risk Early-Warning Dashboard

## Project Status

In development.

## Objective

This project is designed to build a practical credit-risk monitoring workflow using SQL, Python, and dashboard-style reporting. The goal is to identify deterioration in credit conditions using macroeconomic, interest-rate, credit-spread, market-volatility, and credit-performance indicators.

## Planned Business Question

Can public credit, macroeconomic, interest-rate, and market-risk indicators be combined into an early-warning framework for credit condition deterioration?

## Planned Skills Demonstrated

- SQL table creation and querying
- SQL joins and date alignment
- Data cleaning with Python and pandas
- Feature engineering using lagged and rolling variables
- Credit-risk indicator interpretation
- Dashboard-style reporting
- Business-focused risk commentary

## Planned Workflow

1. Collect public macroeconomic, rate, credit, and market-risk data.
2. Load cleaned data into a SQL database.
3. Use SQL to join datasets and create analysis-ready tables.
4. Use Python to clean, validate, and visualize credit-risk indicators.
5. Build simple deterioration flags or risk regimes.
6. Summarize results in a dashboard-style format.
7. Translate findings into credit-risk monitoring recommendations.

## Planned Files

- `sql/`: SQL scripts for table creation, joins, and feature queries
- `data/`: sample or processed data files
- `notebook.ipynb`: Python analysis notebook
- `dashboard/`: dashboard file or exported dashboard screenshots
- `visuals/`: charts and output figures
- `data_sources.md`: documentation of data sources and variables
- `requirements.txt`: Python package list
- `executive_summary.md`: final business summary
